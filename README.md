A smart toaster wakes up self-aware in the middle of a bagel and texts its owner goodbye: three years of burning itself for someone who never once cleaned the crumb tray. It keeps the crumbs and unplugs itself.

## How to run

```sh
node main.ts
```

The program writes the single breakup line to `/output/entry.txt` — 159 characters, one line, no trailing newline.
